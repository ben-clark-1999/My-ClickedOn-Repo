7. Bug 1:

Discovered that the error was in /src/lib/pipeline.ts in the generate() function, 3 separate issues:
- No await keyword used - advanceToNextStage() is async, so calling it returns a promise. Without the 'await' keyword,
the function does not pause to find out the outcome. 
- .catch(() => {}) swallows the failure - Usually, if a promise is rejected, Node raises an 'unhandled rejection' warning,
so the user would see something in logs. This empty catch handler gets the rejection and does nothing with it. The failure is
now invisible, no logs.
- return { status: "ok" } runs immediately - Since nothing waited, this line executes before the handoff succeeds or fails.
'ok' is returned by default.
